📷 Pemindai QR SiPustaka SD Digital

Halaman kamera terpisah untuk peminjaman, pengembalian, kunjungan, dan ISBN.

Tekan “Mulai Kamera”, lalu izinkan akses kamera jika diminta.

Arahkan kamera ke QR/barcode sampai kode terbaca. Hasil akan dikirim otomatis ke tab SiPustaka. Jika kamera tidak muncul, pastikan halaman ini dibuka menggunakan HTTPS dan izinkan kamera untuk situs GitHub Pages.
